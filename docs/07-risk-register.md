# 初步技术风险清单

概率和影响是启动估计，未宣称风险已经发生或解决。每次组会用真实证据更新状态。

| ID | 风险/概率·影响 | 触发信号 | 应对与验证 | 责任人/状态 |
|---|---|---|---|---|
| R-01 | 五人环境不一致；高·中 | 有人无法运行Java/Node/数据库，锁文件不一致 | 固定目标版本与锁文件，按README复现，统一CI；记录环境和失败日志，不全局覆盖个人配置 | 成员5；待复现 |
| R-02 | GitHub CLI/权限/私有仓库保护受限；中·高 | 无法建远程、推送、邀请或开启保护 | 查看[协作指南](../CONTRIBUTING.md)中的保护状态，合并前核对批准和检查结果 | 成员1，跟踪 #8 |
| R-03 | MinIO镜像不可取得或环境不能运行Docker；高·中 | 拉取官方镜像失败/缺Docker | `FileStorage`隔离，第二周先私有本地适配器；可选storage overlay只接受核验过的镜像；真实MinIO联调另记 | 成员5；待环境确认 |
| R-04 | 把偏好误当同意或授权被绕过；中·高 | 高分照片含DENY/PENDING仍入选 | 分表分接口、统一服务端策略；推荐及导出负向测试；管理员不能代签 | 成员3，4协助；待测试 |
| R-05 | 图片修改或出镜标记变化仍继承旧授权；中·高 | 导出版本与同意版本不同 | 不可变版本ID，授权绑定用途/主体集合；变更后PENDING，导出再校验 | 成员3/5；待测试 |
| R-06 | 贪心策略不能改善少数人体验；中·中 | 构造案例中总分高但某人效用很低 | 和总分基线比较；公开启发式限制，优先保证硬约束；公平指标待真实用户确认 | 成员4；待实验 |
| R-07 | 上传文件伪装、超限或解码资源耗尽；中·高 | 非图片伪造扩展名/超大像素 | 解码验证、文件与像素双上限、随机对象键、私有目录/桶；不接收任意磁盘路径；异常测试 | 成员5；待实现 |
| R-08 | 身份未确定导致越权/接口无法联调；高·高 | 业务body传userId代替认证，前端假身份被信任 | 服务器认证上下文和权限策略先定；第二周测试夹具只在测试用；真实登录方案待确认，不开放未保护业务接口 | 成员3；待确认 |
| R-09 | 第三方集成要求被忽略；中·中 | 把MinIO部署当成课程外部业务集成 | 第一周明确第三方登录或消息服务候选；确认可用性和隐私范围，本轮仅定边界 | 成员3；待教师/团队确认 |
| R-10 | 模块接口和多人改共享文件冲突；高·中 | 同名ID含义不同，DTO各写一套 | OpenAPI样例先评审，按模块归属，小PR，公共文件变更点名调用方；运行契约样例 | 全体，成员1跟踪；待执行 |
| R-11 | 真实照片/访谈信息或密钥泄露；中·高 | .env/原图/访谈实名出现在PR | 模拟数据起步，仓库私有仍最小化数据；只提交.env.example；变更前检查；真实数据不放AI提示 | 全体，成员4汇总；持续检查 |
| R-12 | AI脚手架被算作个人独立工作；中·高 | 成员不能解释负责模块、缺少真实评审 | 每人阅读修改并做实际测试，记录AI用途，核心逻辑本人讲解；不虚构个人贡献或PR数量 | 全体；待评审 |

前两周优先关闭或明确R-01/02/03/08的环境和身份阻塞，并用测试约束R-04/05。尚无实际数据证明上传规模、性能或公平性目标已经达成。
