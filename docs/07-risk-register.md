# 初步技术风险清单

概率和影响为启动估计。状态根据[工程验证记录](验证记录.md)及对应 Issue 更新。

| ID | 风险/概率·影响 | 触发信号 | 应对与验证 | 责任人/状态 |
|---|---|---|---|---|
| R-01 | 开发环境不一致。高·中 | 有人无法运行Java/Node/数据库，锁文件不一致 | 固定目标版本与锁文件，按README复现，统一CI。记录环境和失败日志，不全局覆盖个人配置 | 基础设施维护者。待复现 |
| R-02 | 合并规则和协作文档失配。中·高 | 旧模板缺少 Code Owner，或把非必需检查写成必需项 | 以 GitHub 的主线规则为准，核对[协作指南](../CONTRIBUTING.md)及 PR 检查结果 | 活动维护者。主线保护已生效，各成员复现见 [#8](https://github.com/Jdeciderz23/frame-and-say/issues/8) |
| R-03 | MinIO镜像不可取得或环境不能运行Docker。高·中 | 拉取官方镜像失败/缺Docker | 通过 `PhotoStorage` 隔离存储，默认使用私有本地目录。可选storage overlay只接受核验过的镜像。真实MinIO联调另记 | 基础设施维护者。待环境确认 |
| R-04 | 把偏好误当同意或授权被绕过。中·高 | 高分照片含 DENY/PENDING 仍入选 | 分表分接口、统一服务端策略。推荐及导出负向测试。管理员不能代签 | 授权与推荐维护者。授权策略有集成测试，推荐和导出仍待接入验证 |
| R-05 | 图片修改或出镜标记变化仍继承旧授权。中·高 | 导出版本与同意版本不同 | 不可变版本 ID，授权绑定用途和名单修订。变更后重新确认，导出再次核验 | 身份、照片维护者。名单修订已验证，改图生成新版本及导出流程待验证 |
| R-06 | 贪心策略不能改善少数人体验。中·中 | 构造案例中总分高但某人效用很低 | 和总分基线比较。公开启发式限制，优先保证硬约束。公平指标待真实用户确认 | 推荐维护者。待实验 |
| R-07 | 上传文件伪装、超限或解码资源耗尽。中·高 | 非图片伪造扩展名/超大像素 | 解码验证、文件与像素双上限、随机对象键、私有目录/桶。不接收任意磁盘路径。异常测试 | 基础设施维护者。伪装格式和文件大小边界已有测试，补充像素边界和存储失败用例 |
| R-08 | 身份未确定导致越权/接口无法联调。高·高 | 业务body传userId代替认证，前端假身份被信任 | 服务器认证上下文和权限策略先定。合成身份用于本机联调和测试。真实登录方案待确认，不开放未保护业务接口 | 身份维护者。待确认 |
| R-09 | 第三方登录供应方不可用或索取过多权限，中·高 | 回调失败、账号重复绑定、授权范围超过登录所需 | 使用测试账户走查登录、撤销与重新绑定，确认最少必要字段 | 身份模块维护者，方案待验证 |
| R-10 | 模块接口和多人改共享文件冲突。高·中 | 同名ID含义不同，DTO各写一套 | OpenAPI样例先评审，按模块归属，小PR，公共文件变更点名调用方。运行契约样例 | 全体，活动维护者跟踪。待执行 |
| R-11 | 真实照片/访谈信息或密钥泄露。中·高 | `.env`、真实照片或访谈实名出现在提交或 PR | 公开仓库仅使用合成样例和去标识化纪要，环境变量只提交示例，真实数据留在团队限制访问的位置 | 全体，推荐维护者 汇总。持续检查 |

开发环境、存储适配与正式身份方案按对应 Issue 跟踪。推荐和导出接入时需补齐授权回归测试。
